你的 iPhone。
你的車載螢幕。

在車載螢幕上使用地圖、音樂與通話。SBplay 為相容的 Android 車機帶來有線與無線 CarPlay，採用熟悉的 DiAuto 介面。

下載 APK ↓安裝方式

無須越獄、轉接盒、帳號或驗證伺服器。

僅適配領克 CS11 車機（Android 4.4.3 / API 19 / 32 位元 ARM）。請將 SBplay 安裝到車機，而非 iPhone；相容性取決於車機韌體與 iOS 版本。

SBplay 僅針對領克 CS11 平台。本分支不支援比亞迪 DiLink 或其他 Android 車機。

熟悉的駕乘體驗

01

安裝到車機

  1. 停車後開啟 CS11 車機的除錯或安裝功能，將 SBplay APK 安裝到車機。
  2. 在 iPhone 開啟藍牙與 Wi-Fi，並與車機藍牙配對。
  3. 無線 CarPlay：開啟車機熱點，在 SBplay 選擇無線模式，依照手機提示操作。
  4. 有線 CarPlay：使用可傳輸資料的 USB 線，在 SBplay 選擇 USB 模式並確認手機提示。

日常使用不需要 ADB。APK 安裝方式取決於車機。無須手動輸入 MAC 位址。

這是未經 Apple 認證的實驗性 CarPlay 接收端，配件身分可能失效。功能須在 CS11 實車驗證。
