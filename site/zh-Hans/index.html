你的 iPhone。
你的车载屏幕。

在车载屏幕上使用地图、音乐和通话。SBplay 为兼容的安卓车机带来有线和无线 CarPlay，采用熟悉的 DiAuto 界面。

下载 APK ↓安装方法

无需越狱、转接盒、账号或认证服务器。

仅适配领克 CS11 车机（Android 4.4.3 / API 19 / 32 位 ARM）。请将 SBplay 安装到车机，而非 iPhone；实际兼容性取决于车机固件与 iOS 版本。

SBplay 仅面向领克 CS11 平台。本分支不支持比亚迪 DiLink 或其他安卓车机。

熟悉的驾乘体验

01

安装到车机

  1. 停车后开启 CS11 车机的调试/安装入口，将 SBplay APK 安装到车机。
  2. 在 iPhone 上开启蓝牙和 Wi-Fi，并与车机蓝牙配对。
  3. 无线 CarPlay：开启车机热点，在 SBplay 中选择无线模式，按手机提示操作。
  4. 有线 CarPlay：使用支持数据传输的 USB 线，在 SBplay 中选择 USB 模式并确认手机提示。

日常使用不需要 ADB。APK 安装方式取决于车机。无需手动输入 MAC 地址。
