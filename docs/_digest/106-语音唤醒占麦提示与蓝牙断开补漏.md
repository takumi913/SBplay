# 106 · 语音唤醒占麦提示 + 蓝牙断开补漏（2026-11-11，未上机）

> 起因：有人告诉车主，CS11 上 CarPlay 麦克风不能用，是因为车机语音唤醒一直占着麦克风：
> 点车机左上角笑脸图标，关掉「小度小度」和「嗨领克」的监听即可。另外 CarPlay 连上后要主动断开
> 手机的蓝牙（A2DP/HFP），否则打电话时会被车机蓝牙电话接走。
> **本篇的改动都必须上机复验。** App **不会**自动关唤醒，也**不会**去杀车机上的任何进程（车主明确不要）。

## 1. 语音唤醒占麦：只提示，不动车机

| 位置 | 改了什么 |
|---|---|
| 首页 | 底部常驻一行灰字：通话对方听不到？点左上角笑脸，关掉小度小度/嗨领克 |
| 设置 → 音频路由 | 原提示改成准确路径（笑脸图标 → 关两个唤醒词 → 重新拨打） |
| 通话中 | `MicrophoneUplink` 发现「所有音源被拒」或「开麦前 3 秒全是精确的 0」时写 `Microphone: blocked type=.. reason=all-sources-refused/digital-silence`，CarPlay 画面上弹两次 Toast（约 7 秒）提示关唤醒；每个会话只弹一次 |
| 诊断页 | 录到静音（不论 telephony 还是别的类型）、所有音源被拒：第一步都改成“关语音唤醒再打一次”，setprop 两个开关降为第二步 |

判据只用**精确的 0**：真实麦克风总有底噪，司机只听不说也不会全 0，所以不会误报。

`MicrophoneAvailability`（一次性麦克风探测）删除：没有任何调用方，且它把“能读到但全是 0”判成可用。

## 2. micMute 强制解除

`AndroidMediaSink` 开麦前若 `AudioManager.isMicrophoneMute == true`，先 `setMicrophoneMute(false)`，
写 `Audio: micMute cleared before capture ...`；最后一路麦克风结束时恢复为 true（`Audio: micMute restored`），
车机状态原样还回去。诊断页判断“系统静音”时不再看开麦前那一行 `when=mic-requested`。

## 3. 蓝牙断开补漏（`PhoneMediaAudioWatchdog`）

原有机制不变：会话建立/`disableBluetooth` 时断 A2DP+HFP（26 秒重试梯），之后每 5 秒检查，会话结束还回去。补了四处：

1. **一次 tick 两个都断**：以前 A2DP 断成功就 return，HFP 要等下一个 tick（再晚 5 秒）。
2. **事件触发立即断**（`releasePhoneBluetoothOnEvent`）：
   - CarPlay 来电/去电/推断的 VOIP 通话出现时（`CarPlayGlance.callListener`），日志 `bluetooth release requested by call ringing/active`；
   - 会话期间收到选定 iPhone 的 `ACL_CONNECTED`（`PhoneBluetoothReceiver`），日志 `... by phone bluetooth reconnected`。
     这台 ROM 是否投递该广播**未确认**，上车看有没有这行。
3. **地址变了跟着换**：watchdog 运行中再次 `start()` 时，如果存储的手机地址变了（先猜了已配对 iPhone、后来 `onDeviceInfo`
   拿到真实 deviceId），改用新地址，日志 `phone media watchdog now follows <addr> (was <addr>)`。以前会一直用旧地址，
   家里多台 iPhone 时真手机的 HFP 永远断不掉。
4. **只留一个 watchdog**：Service 和 Activity 共用 `PhoneMediaAudioWatchdog.shared()`，不再两个并行 tick。

只断 profile，不关蓝牙适配器、不断 ACL——无线 CarPlay 重连还要用蓝牙。

## 4. 复验清单

1. 唤醒**开着**连 CarPlay 打微信语音：应在 3 秒左右弹出 Toast；日志有 `Microphone: blocked`；诊断页第一步是关唤醒。
2. 按笑脸关掉两个唤醒词，重新拨打：不再弹 Toast，诊断页 `peakMax` 应在几千以上。
3. 通话中看车机屏幕：不应出现车机自己的蓝牙电话界面；日志有 `bluetooth release requested by call ...`。
4. 断开 CarPlay 后手机蓝牙应自动回来（原有行为，确认没被改坏）。
