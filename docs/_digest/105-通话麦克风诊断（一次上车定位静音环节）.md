# 105 · 通话麦克风诊断：一次上车定位“对方听不到”卡在哪一环（2026-11-10，未上机）

> 起因：车主反馈微信语音通话（接、打都一样）车机麦克风完全没声音。现有报告分不清
> “iPhone 没要麦克风 / 麦克风没打开 / 录到的是静音 / 没发出去”，而这台 ROM 的 logcat
> 收不到应用自己的 `Log.i`（例如 `microphone level peak=`），所以只能靠会话日志文件。
> **本篇只加日志和判读，不改任何音频行为。必须上机复验。**

## 1. 新增的日志口径（都写进会话日志，失败详情页能看到）

| 行 | 何时写 | 回答的问题 |
|---|---|---|
| `Audio: setup type=.. stream=.. codec=.. input=.. dataPort=yes/no mic=planned` 或 `mic=skipped reason=..` | 每一路音频 SETUP | iPhone 有没有向车机要麦克风；没要的原因 |
| `Audio: downlink started/stopped type=..` | 下行首包 / 下行结束 | 麦克风要等下行首包才启动，下行没来就不会开麦 |
| `Microphone: switches type=.. mic_effects=on/off mic_mode=on/off appliesToThisStream=..` | 每次开麦前 | 两个 CS11 通话开关当时的值，以及对这一路是否生效（只对 telephony） |
| `Microphone: probe .. candidate=<音源> result=<读到的字节或错误码>` | 音源阶梯每个候选 | 哪个音源被车机拒绝（-3 多半是语音助手占着麦克风）；-1000 建不出录音器，-1001 初始化失败 |
| `Microphone: effects .. applied=yes aec=enabled ns=enabled` / `applied=no reason=..` | 开麦时 | 回声消除/降噪到底有没有挂上 |
| `Microphone: start .. actualSource=<音源>` | 开麦成功 | 实际用的音源（`source=` 是请求的音源，阶梯可能换成别的） |
| `Microphone: stats .. frames=.. silentFrames=.. peakMax=.. ended=..` | 每 5 秒 | 该窗口的音量；静音帧=峰值 < 64 |
| `Microphone: summary .. seconds=.. frames=.. silentFrames=.. peakMax=.. udpSent=.. sendErrors=..` | 一次开麦结束 | 整次通话的总账 |

`Microphone: start/stats/summary` 的 `type=` 现在区分 `default` 和 `compatibility`（以前都写 `other`），
因为微信通话走哪一类还没确认（见 15e7857 / VoiceCallWatch）。

## 2. 失败详情页的【通话麦克风诊断】（`MicrophoneDiagnosis`）

位置：失败摘要和崩溃信息之后、完整日志之前。入口不变：首页“查看失败详情”（有失败时），
或 设置 → 诊断 → 查看最近错误（任何时候）。判读顺序：

1. 有开麦记录：取通话类开麦里采集最多的一次
   - 一字节没读到 → 麦克风打开但没数据
   - `udpSent=0` → 录到了但没发出去
   - 失败包 > 10% → 发送失败
   - 没有音量字段 → 旧版本日志，判断不了
   - `peakMax ≥ 300` → **车机这端正常**，问题在 iPhone 收到之后
   - `peakMax < 300` → 录到的是静音：telephony 时列出回声消除/通话模式状态并给出 `setprop` 下一步；
     非 telephony 时明确“两个开关不生效”，指向录音输入本身
2. 只有 `Microphone: failure` → 按 stage 说明（RECORDER_* = 所有音源被拒，多半语音助手占用）
3. 有 `mic=planned` 但没开麦 → 下行没开始 / 日志被截断
4. 只有 `mic=skipped reason=mic-disabled` → 没有录音权限
5. 有音频流但从没要过麦克风 → 通话没走 CarPlay，最常见是 HFP 被车机原生蓝牙电话接走（日志有 `hfp=true` 时点明）
6. 连音频流都没有 → 没走到音频阶段或旧版本

阈值 300 的依据：2026-10-08 车上静音采集峰值 5，台架正常说话 5000–18800（提交 2374009）。

## 3. 复验清单

1. 连上 CarPlay，打一通微信语音（对方说话、自己说话各十几秒），挂断。
2. 不要重新连接，进 设置 → 诊断 → 查看最近错误，拍【通话麦克风诊断】那一页。
3. 预期：能看到 `Audio: setup` 行；如果开了麦，能看到 `Microphone: summary` 和结论。
4. 若结论是“录到的是静音且走 telephony”，按页面给出的 `setprop` 再测一次，对比两次的 `peakMax`。
