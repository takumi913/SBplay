领克 CS11 车机的 CarPlay 接收端，基于 [DiPlay](https://github.com/shihabal3amri/DiPlay)，只适配 CS11。

> 非 Apple 认证产品。CarPlay 是 Apple Inc. 的商标；本项目与 Apple、领克、吉利、亿咖通均无关联。

## 功能

- 无线 CarPlay
- 有线 CarPlay
- 仪表显示导航和音乐

## 状态

| 功能 | 状态 |
|:---|:---|
| 无线 CarPlay | 可用 |
| 有线 CarPlay | 可用 |
| 仪表导航、媒体卡片 | 可用 |
| 仪表专辑封面 | 未完成 |
